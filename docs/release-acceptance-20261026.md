## 本次修复

- 前端确认按钮和聊天发送加入正在提交的锁，避免连续点击产生并行请求。
- 无效 JSON、聊天流提前结束及网络中断不会再当成成功；写操作结果不明时要求先核对记录，不自动重发。
- 模型系统上下文补齐扩展业务资源标识，移除不必要的存单金额；保留银行领域、工具白名单和确认边界。
- 启动时本地 API 令牌采用先设置私有 ACL 再原子写入；已有令牌及模型 Key 文件也校验权限。
- Windows 隔离运行时从对应 Python 3.13 基础安装复制，修复虚拟环境启动器缺少标准库的问题，不放宽隔离权限。
- Cloudflare 静态资源加入 CSP、防嵌入、禁止 MIME 嗅探及无来源引用等响应头。API 源站必须显式配置 HTTPS；交付配置不包含原开发者源站或账号路由。
- 补齐 Windows 可安装的本地 EVM 依赖和公开编译产物；测试校验源码摘要，避免拿过期字节码充数。
- 普通启动脚本清除继承的模型凭据；受限 DeepSeek 入口需显式启用模型。
- 导出器排除敏感数据并拒绝已检测到的秘密，加入对应测试；PowerShell 以 UTF-8 BOM 输出，避免旧版 PowerShell 中文解析错误。
