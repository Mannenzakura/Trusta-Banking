# 原版银行项目资料

这里保留原个人银行项目的银行模块：前端页面与字体/航司标识、Worker 业务代码、迁移结构、测试、开发脚本及历史交付记录。它是新 TRUSTA 版本的功能来源与研究参考，不参与根目录产品启动。

来源是替换队友版本前保留的冻结快照。所有文件清单及摘要见 `SOURCE-MANIFEST.json`。未包含个人数据库、API Key、支付私钥、部署凭据、缓存、重复构建产物，以及与银行无关的无人机/壁纸等独立项目。

历史文档中的“通过”“已部署”、接口用量和外部行情均属于当时版本，不能当作当前验收结论。旧版有独立支付宝/Duffel/航班 API 试验，而当前产品按用户决定通过官方站点完成出行、缴费等外部业务。本目录不自动启用这些接口。

这里保留原有测试和依赖锁文件，但没有在本次发布中逐项复测所有旧版业务。不要对真实账户运行历史 `verify-*-paid`、部署或密钥配置脚本。根目录 `README-交付与验收.md` 和本次验收报告才是当前版本的启动与验收依据。

`tests/bank-scenarios.test.mjs` 和 `tests/bank-accounts.test.mjs` 使用公开的 RFC 6238 SHA-1 测试向量，不是任何人的验证码密钥。公开前扫描只对这两个路径中的该精确测试值豁免，真实密钥不得豁免。
